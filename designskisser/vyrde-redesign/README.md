# Vyrdepil — designhistorikk

Dette er arbeidsnotat frå utviklinga av designsystemet. Nokre av skissene
omtalar pilotar, kategori-trekkspel, eldre logoavgjerder og stegvis migrering.
Dei er historiske og skal ikkje brukast som gjeldande krav.

Gjeldande instruksar ligg samla her:

- [Utviklingsreglar](../../AGENTS.md) — arkitektur, personvern, kvalitet og arbeidsflyt.
- [Designinstruks](../../DESIGN.md) — komponentar, palett, appbreidd og responsiv utforming.
- [Komponentkatalog](../../designsystem/index.html) — levande døme frå dei same filene som sidene lastar.
- [Kjeldesjekk](../../designsystem/check-stylesheets.cjs) — kontrollerer alle HTML-ruter for manglande og utgåtte stil-/skriptlenkjer.
- [Designkontroll](designkontroll.json) — dato, omfang og avgrensingar for kjeldesjekken og nettlesarprøvene.

Når eit gammalt arbeidsnotat er i konflikt med `AGENTS.md` eller `DESIGN.md`,
gjeld dei to sentrale dokumenta.
