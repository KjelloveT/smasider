# Godkjende fellesressursar for Vyrdepil

Denne mappa inneheld berre optimaliserte filer som blir brukte av den nye fellesretninga. Kjeldene og fulloppløyste originalar ligg lokalt under `_kjelder/` og blir ikkje publiserte.

| Filer | Bruk |
| --- | --- |
| `vyrde.png` | Stein-Vyrde i toppmeny, appmeny og ved hero. |
| `hero.png`, `hero-post.png` | Hero-skilt og heil stolpe. |
| `post-top.png`, `post-bottom.png` | Godkjende stolpeendar for skilt. |
| `post-ground-left.png`, `post-ground-right.png` | Ulike føter med steinar som står ned i bakken. |
| `wood-contours.png` | Stort roleg kotemønster på hovudboksar. |
| `corners/corner-01.png` … `corner-10.png` | Den godkjende ornamentbanken. |
| `logos/*-mala.png` | Dei valde app-logoane i «Måla flater»-stilen. |
| `backgrounds/` | 144 norske landskap; reservasjonane ligg i `json/vyrdepil-design.json`. |
| `landscapes/` | Tre godkjende grunnmotiv for dømevisinga. |

Logoar er maksimalt 384 px og har 128 fargar. Bakgrunnar er progressive JPEG-ar, maksimalt 1920 px og under 500 kB kvar. Ingen tekst, skilt eller UI er teikna inn i landskapsbileta.
