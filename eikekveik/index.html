Eikekveik

Lag tankekart, idémyldring eller flytskjema. Klikk + på ein node for å leggje til ei grein, dobbeltklikk for å skrive, og dra nodane dit du vil.

Dobbeltklikk på tom flate for ein ny node. Klikk på ei line for å velje strek eller piler. Dra i tom flate for å flytte kartet, og zoom med Ctrl + hjul eller to fingrar.

Vel ein node eller ei line for å endre eigenskapane.
