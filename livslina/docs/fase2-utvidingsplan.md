# Fleire vegar gjennom Livslina

Arbeidsplan frå 22. november 2026. Same figur held fram frå vidaregåande og
tek med seg karakterar, fagbrev, pengar, bustad og tidlegare val. Årsplanen
skal gjere det lett å forstå kva eit val opnar, kva det kostar og kva som
endrar seg fram til neste sommar.

## 1. Utdanning, yrke og eit år til å prøve noko nytt

Bygg katalogen av **utdanningsløp, kvalifikasjonar og yrke**. Eitt løp kan
opne fleire yrke, og eitt yrke kan ha fleire vegar inn. Til dømes kan eit
fagbrev gi arbeid fyrst, fagskule ved sida av jobb seinare og eit nytt
arbeidsansvar etterpå. Ei rolle kan dele økonomi- og hendingslogikk med
liknande roller og få sine eigne oppgåver, arbeidstider og val.

Bruk fagfelt som elevane lett finn fram i. Mål for den breie leveransen er
30–40 spelbare inngangar og minst 60 namngjevne yrkesroller, med deltids- og
vidareutdanningsvegar der det passar. Bruk STYRK-08 til å kontrollere dekninga.
Leiarroller og andre stillingar som krev erfaring kan visast som seinare steg.
Bruk yrkesskildringane frå Utdanning.no som fagleg kjelde, skriv eigne korte
tekstar og avklar bruksvilkår før eventuelle datauttak. [Utdanning.no](https://utdanning.no/jobbkompasset/) · [SSB si yrkesklassifisering](https://www.ssb.no/klass/klassifikasjoner/7)

| Fagfelt | Døme på retningar og roller som skal dekkjast |
| --- | --- |
| Helse og omsorg | Helsefagarbeidar, sjukepleiar, vernepleiar, fysioterapeut, lege |
| Oppvekst og utdanning | Barne- og ungdomsarbeidar, barnehagelærar, grunnskulelærar, faglærar |
| Sosialt arbeid og offentleg teneste | Sosialarbeidar, rettleiing, forvaltning, jurist |
| Bygg og handverk | Tømrar, røyrleggjar, elektrikar, byggdrift, byggingeniør |
| Industri og energi | Industrimekanikar, prosessoperatør, automatikar, arbeidsleiar |
| Data, design og teknologi | IT-drift, utviklar, teknisk design, ingeniør |
| Natur, landbruk, hav og realfag | Gartner, agronom, akvakulturarbeidar, biolog, laboratoriearbeid |
| Transport og logistikk | Lagermedarbeidar, logistikkoperatør, yrkessjåfør, maritime fag |
| Sal, service, mat og reiseliv | Butikk, kundeservice, kokk, hotell, reinhald |
| Økonomi, kontor og leiing | Kontormedarbeidar, rekneskap, innkjøp, HR, administrasjon |
| Kultur, media, idrett og kreative fag | Grafisk design, foto, lyd, bibliotek, aktivitet og trening |
| Tryggleik og beredskap | Vektar, politi, brann og redning, forsvar. Vis særkrav før start. |

Fyrste pakke bør gi fleire tydelege vegar frå både studiespesialisering og
yrkesfag. Utvid mellom anna med fagskule innan bygg eller automasjon, arbeid
innan service og logistikk, ingeniørfag, helse- og sosialfag og kreative fag.
Ta inn to eigne eittårsval i same pakke.

- **Folkehøgskule.** Vel til dømes friluftsliv, musikk eller media. Lag eigne
  val om linje, internat, utstyr, turar og lån. Internatprisen må vise kva som
  er inkludert, slik at kost og losji blir rekna éin gong. Året gir nye
  erfaringar, vener og ein ny sjanse til å velje retning. Dokumenter eigne
  opptaks- og støttevilkår for dei linjene spelet brukar. [Folkehøgskolane](https://www.folkehogskole.no/om-folkehogskole/sann-soker-du-pa-folkehogskole) · [Lånekassen](https://lanekassen.no/nb-NO/stipend-og-lan/norge/folkehogskole-i-norge/)
- **Reiseår.** Planlegg anten ei lengre reise eller ein kombinasjon av nokre
  reisemånader og nokre arbeidsmånader. Vis transport, overnatting, mat,
  forsikring og buffer for heimreisa. Oppseiing eller vidare leige heime skal
  vere eit budsjettval. La spelaren korte ned turen, utsetje han eller arbeide
  meir dersom budsjettet blir for stramt. Inntekt og reiseutgifter følgjer
  månadene der dei faktisk kjem. Bruk spelanslag med tydeleg prisår.

### Fyrste årsplan og byte av retning

1. Vis kva spelaren har med seg frå VGS. Ein med fagbrev får sjå korleis ein
   kan bruke faget med ein gong. Har figuren eit påbegynt løp, ligg **Hald fram**
   fyrst med attståande tid og neste steg.
2. Del **Utforsk retningar** i korte steg. Start med **Studer**, **Gå i arbeid**
   eller **Ta eit år til å prøve noko nytt**. Vel så fagfelt og konkret løp.
   Legg til søk og filter for kva figuren kan starte no og kva som krev eit
   mellomsteg. Kvart kort viser lengd, vilkår, relevante yrke og eit døme på
   studie- eller arbeidskvardagen. Vis budsjettet når eit alternativ er valt.
3. Vis konsekvensen med ein gong spelaren vel noko anna enn ei påbegynt eller
   vidareført retning. Stadfest ved årsstart. Døme for eit påbegynt løp:
   «Du set sjukepleiestudiet på pause for å ta eit reiseår. Det fullførte
   studieåret er lagra. Sjå budsjettet for reisa før du startar.» Ved fyrste
   årsplan etter fagbrev kan teksten vere «Du tek eit friår i staden for å
   gå vidare som tømrar no. Fagbrevet er framleis ein del av kompetansen din.»
   Bruk stadfestinga også ved seinare byte. Valet gjeld fyrst når spelaren
   stadfestar. Eit vanleg fyrstegongsval eller overgang til jobb etter den
   same graden treng berre vanleg årsstart.
4. Attende til eit påbegynt løp skal spelet vise kva som er fullført, kva som
   står att og korleis retur verkar på pengar og tid. Godskriving mellom to
   ulike løp krev ei definert kopling. Ferdige kvalifikasjonar, gjeld og
   påbegynt utdanning skal følgje figuren også vidare frå 25 år.

### Opptak og data for mange retningar

- Lagre opptak per løp, lærestad, år og kvote, med kjelde og dato for sjekk.
  Skil studiekompetanse, fagbrev og særkrav frå poeng i konkurransen. I den
  breie katalogen må «alle kvalifiserte kom inn» og «ukjend poenggrense» vere
  to ulike statusar. For regulerte yrke må data vise stega fram til å kunne
  arbeide i yrket. [HK-dir sine poenggrenser i 2026](https://hkdir.no/rapporter-undersokelser-og-statistikk/les-rapporten/tilbudstall-for-universitet-og-hogskoler-i-samordna-opptak-2026/studier-med-hoy-poenggrense)
- Gi spelaren minst eitt konkret neste val når det stengjer. Døme er å søkje
  ein annan stad, ta påbygg eller setje av tid og pengar til privatisteksamen.
  Planlegg privatisteksamen som ei kvalifiserande handling med førebuing,
  avgift, nytt resultat og høve til å prøve att. Bevar det opphavlege snittet
  slik at forbetra fag berre slår ut i kvoten som kan bruke dei. Hald
  opptaksreglane versjonerte når aldersgrenser og tilleggspoeng endrar seg.
  [Samordna opptak om forbetra fag](https://www.samordnaopptak.no/universitet-og-hogskole/poengberegning/forbedringer-og-nye-fag/) · [Regjeringa om nye opptaksreglar](https://www.regjeringen.no/no/aktuelt/slik-blir-de-nye-reglene-for-opptak-til-hoyere-utdanning/id3118553/)
- Bruk lokale datafiler med stabile ID-ar og eigne profilar for arbeidskvardag,
  opptak og økonomi. Legg inn datakontroll for manglande kjelder, brotne
  koplingar og roller som ingen kan nå. Ta med representative arbeidsvilkår
  i hendingane, som praksis, turnus, samarbeid eller pendling. Vis når løn
  og utgifter er spelanslag. Spelinga skal fungere utan nett.

## 2. Transport og førarkort

Transport ligg no som ein fast kostnad. Lat eit val i årsplanen erstatte den
posten med reiseveg, tidsbruk og månadspris. Start med tre oppdikta miljø
med ulik reiseveg og tilgang på kollektivtransport, til dømes by, tettstad
og område med spreidd busetnad. Ingen faktiske adresser trengst.

- Lat spelaren gå, sykle, ta buss eller tog, samkøyre eller køyre bil når
  reisevegen og årsplanen gjer det mogeleg. Ei sein vakt eller eit nytt
  praksissted kan endre kva som fungerer. Vis i same val til dømes kor mykje
  tid ei rimelegare reise tek frå kvile eller fritid.
- Gjer **Førarkort klasse B** til ei framdrift i Transport. Del det i
  grunnkurs, køyreopplæring, teori og oppkøyring. Rekn kostnad og tid per steg.
  Skil øvingskøyringsrett frå bestått førarkort. Utbetaling og framdrift kjem
  når steget blir gjennomført, og spelet hugsar dette frå år til år. Legg
  inn høve til ekstra øving og ny prøve med synlege vilkår og kostnader.
  Den som tek opplæringa på trafikkskule skal òg kunne verte ferdig. Bruk
  aldersgrensa frå Statens vegvesen for bestått klasse B. [Statens vegvesen](https://www.vegvesen.no/forerkort/ta-forerkort/veien-til-forerkortet/personbil-b/) · [Aldersgrenser](https://www.vegvesen.no/forerkort/ta-forerkort/oppkjoring/aldersgrenser-for-oppkjoring/)
- Gje førarkort og sykkel eller bil kvar si handling i ei felles oversikt
  **Bustad og eigedelar**. Rombutikken kan få ein snarveg til Transport.
  Vis bilkjøp, forsikring, drift, vedlikehald og verditap kvar for seg.
  Biltilgang og førarkort er eigne vilkår. Fyrste pakke kan bruke kontantkjøp
  av bruktbil og sal. Vis bileigarens reelle månadsutgifter før kjøpet.
  [SIFO sitt referansebudsjett](https://www.oslomet.no/om/sifo/referansebudsjettet/)

## 3. Bustad, rom og innkjøp

Bygg på noverande hybel, kollektiv, leilegheit og hus. Bruk den eksisterande
finansieringa med eigenkapital, inntekt, gjeld og lånekostnad. Utvid bustadvala
med større leigebustad og ekstra rom. Vis korleis ny reiseveg, straum, plass
og faste utgifter slår ut før spelaren stadfestar flytting. [SSB om leige etter romtal og område](https://www.ssb.no/statbank/table/09895)

- La kvar bustadtype avgjere kva rom som kan opnast. Hybelen har eitt rom.
  Leilegheita får soverom, stove og kjøkenkrok. Større bustader kan få
  ekstra soverom, arbeidsrom eller barnerom. Eit barn kan bu i ein mindre
  bustad. Innreiinga viser kva som faktisk får plass der.
- Utvid butikken med brukte og nye ting, romfilter og vising av mål og pris
  før kjøp. Prioriter sitjeplassar, bord, lys, oppbevaring og seng før fleire
  pynteting. Legg til eit lite sett med barneutstyr når familieøkonomien
  er klar. Eit møbel høyrer til inventaret éin gong og kan flyttast, seljast
  eller stå på lager dersom neste bustad er mindre.
- Vis naudsynt utstyr, valfrie kjøp og dekor i romplanen med ulike følgjer.
  Vis verknader av plass og utstyr i konkrete situasjonar. Til dømes kan
  eit bord gi plass til besøk, ei lampe gjere ein lesekrok brukande og ei
  rimeleg løysing fungere godt i eit lite rom. Før ei eingongsutgift éin gong
  i rekneskapen, og sjekk overlapp med faste SIFO-postar for utstyr og møblar.

## 4. Vener, forhold og familieliv

Før vidare ideen om folk som hugsar tidlegare val. Start med ein ven frå VGS
og ein ny person ein kan møte gjennom årsretninga. Legg til høve til å
byggje vennskap, bli kjærastar, vere einsleg, flytte saman eller gå frå
kvarandre. Trivsel og sosialt skal spegle tid, støtte, konflikthandtering og
kvile. Alle desse kvardagane skal kunne fungere godt.

- **Oversikta.** Eit synleg kort for **Hushald og relasjonar** viser kven
  som bur saman, kven ein har nær kontakt med, barn og alder dersom det er
  aktuelt, siste viktige hending og eitt mogeleg neste steg. Til dømes kan
  ein halde kontakten med ein ven, ta ein samtale eller sjå eit avtalt
  omsorgsskifte. Bruk spelpersonar med stabile ID-ar og oppdikta namn.
- **Årsplanen.** Ei eiga fane **Hushald** viser eksisterande avtalar og
  let spelaren velje tid til folk ein bryr seg om, planleggje sambuarskap
  eller planleggje omsorg. Før flytting viser ho konkret husleigedel,
  depositum og utgifter. Ein partnar har eigen inntekt og eigne avtalar.
  Test delt leige fyrst. Ta opp felles kjøp seinare med eigardelar og
  oppgjer ved sal eller brot.
- **Planleggje barn.** Utgangspunktet er **Ingen plan om barn**. Ei
  relasjonshending kan opne ein samtale. Spelet kan berre starte ei
  graviditetslinje etter at spelaren aktivt vel **Planlegg barn**, partnaren
  er samd, og spelaren stadfestar tidspunktet i årsplanen. Vis venta
  omsorgstid, budsjett og permisjon før stadfesting, og gi valet om å vente.
  Dette skal fungere likt etter lagring, ny innlasting og byte av årsretning.
- **Når barnet kjem.** Legg ein avtalt månad inn i kalenderen, med samanhengande
  framdrift over årsskiftet. Planen viser kven som tek omsorg, endringar i
  arbeid og studium, fødselsførebuing, utstyr og seinare barnehage. Gi plass
  til fine kvardagsstunder, lite søvn, vener som hjelper og val om å dele
  oppgåvene. Sjekk vilkår for foreldrepengar, eingongsstønad og barnetrygd
  kvar for seg. Ved brot held barnet fram i spelet med synleg omsorgsdeling,
  bustad og kostnadsdeling. Dokumenter spelmodellen, også for eit hushald med
  éin forelder. [NAV om foreldrepengar og eingongsstønad](https://www.nav.no/foreldrepenger/foreldrepenger-eller-engangsstonad/) · [NAV om barnetrygd](https://www.nav.no/barnetrygd) · [Udir om foreldrebetaling](https://www.udir.no/regelverk-og-tilsyn/barnehage/foreldrebetaling/)

## 5. Illustrasjonar, diorama og romgrafikk

La ei årsrunde vise kva som står på spel i scena. Bruk små diorama i
retningsveljaren og større utsnitt ved hendingar. Bruk dei etablerte
Lucide-ikona ved knappar og tal. Lat kvart diorama ha ein stabil ID og ein
kort motivtekst. Nye sceneillustrasjonar følgjer dei vaksne dioramaa som
alt er i spelet. Rom og ting som ein flyttar på, følgjer
[den målsette v4-rommodellen](../assets/prototype/layout-standard-v4.md) og
[dei etablerte 8-bit-romressursane](../assets/prototype/resources-v5/README.md).

| Studium og arbeid | Seks fagmiljø til katalogen og seks hendingar, til dømes praksisrom, verkstad, kontor, gard, lager og produksjonslokale | Ein grunnscene per fagfelt og nye diorama for praksis, fyrste vakt eller andre val som har ulike følgjer. Del scener mellom beslekta roller. |
| Folkehøgskule og reise | Internat/felleskjøken, linjeaktivitet, togstasjon og ei rimeleg overnatting | Utvid med ei linje eller ein type reise om gongen, saman med hendingane dei treng. |
| Transport | Fire diorama for buss, sykkel, køyretime og oppkøyring | Legg til samkøyring, vintertransport og bil som treng reparasjon når dei vala kjem. |
| Bustad og rom | Kjøkenkrok og oppbevaring for små bustader, deretter ekstra soverom og ei fyrste pakke med 8–12 målsette ting | Legg til brukte variantar, eit praktisk arbeidsrom og eit sett med barneutstyr. Mål og prøv kvar familie i den samansette scena. |

Varier kven som er med utan å endre den visuelle identiteten deira. |

Godkjenn eitt motiv per bildetype i faktisk spelbreidd før resten blir laga.
Ta vare på prompt, stilreferanse, kjeldefil og kontrollert utsnitt. Komprimer
og last lokalt berre dei små bildesetta som trengst. Sjekk lesbarheit på
mobil og prosjektor, bakgrunn og kantar, og at kontrollane framleis er
synlege dersom eit bilete manglar. For rom skal mål, kontaktpunkt, feste,
plass og lagrekkjefølgje vere kontrollerte før ein produserer mange variantar.

## 6. Rekkefølgje og speltest

1. **Karriereval.** Prøv den nye veljaren, fyrste årsstart, konkret
   bytevarsel og retur til eit påbegynt løp. Legg inn dei fyrste nye
   vegane, folkehøgskule, reiseår og tilhøyrande diorama. Sjekk at ein kan
   finne ei mogeleg retning med både fagbrev, høgt snitt og lågt snitt.
   Utvid så breidda fagfelt for fagfelt med kjelder og hendingar.
2. **Transport og bustad.** Spel minst eitt år med kollektivtransport,
   eitt med føraropplæring og eitt med bil. Test at kostnad og tidsbruk
   stemmer med Budsjett. Flytt mellom hybel, leilegheit og hus. Kontroller
   at møblar, depositum, gjeld og eigedelar blir førte éin gong.
3. **Relasjonar og hushald.** Test at to hendingar viser til same ven eller
   partnar over fleire år, med lagring midt i eit år. Prøv einebuande,
   sambuarskap og brot. Legg så til planlagt barn, permisjon og omsorg.
   Test at å vente eller avbryte før stadfesting aldri startar ein graviditet,
   og at barnet og avtalane blir med vidare når ein byter år eller bustad.
4. **Samla kontroll.** Prøv ulike val på telefon, nettbrett og stor skjerm.
   Bruk dei same 50 spelprofilane til å samanlikne økonomien før og etter
   kvar større endring. Sjå på brukskonto, gjeld og nettoformue kvar for
   seg. Prøv vidaregåande, faseovergang, pågåande år og eksport/import av
   gamle og nye spel. Nye lagra opplysningar skal følgje VyrdepilStorage og
   dokumenterast i personvernoversikta.
